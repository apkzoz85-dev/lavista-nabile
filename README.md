# لافيستا سيتي — Landing Page

Next.js 16.3.8 · React 19 · Tailwind 4 · Web3Forms · Static build

## قبل النشر — غيّر في `lib/site.ts`
- `url` — الدومين النهائي
- `web3formsKey` — Access Key من web3forms.com
- `gtagId` + `conversions` (form / whatsapp / call)
- `brand` لو الصفحة هتشتغل باسم غير Grandeur Spaces

الرقم: 01030083122 (اتصال + واتساب). الأسعار والوحدات في `UNITS` في نفس الملف.
